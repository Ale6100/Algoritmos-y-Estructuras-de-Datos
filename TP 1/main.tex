\section{Decisiones, Aclaraciones y Desarrollo.}

Al pensar el problema por primera vez, nos dimos cuenta de que podíamos tratar todo como una transacción. Partimos escribiendo dos observadores: uno donde se cargaban las promociones y otro que era un superobservador que consideraba toda operación como una transacción (Transferencias, Acumulaciones, Canjes). Luego tuvimos que rediseñar los observadores, modularizando entre los diferentes tipos de transacciones, principalmente para las acumulaciones, donde teníamos que conectar también el observador de promociones. Esto nos llevó a terminar modularizando todo en cinco observadores para trabajar de forma prolija.

Estos observadores cubren todos los casos. Con el superobservador anterior no se podían cubrir correctamente, principalmente, los procedimientos acumularMillas y resumenTransacciones. Estos observadores permiten realizar todas las operaciones de forma prolija y sin necesidad de hacer aclaraciones especiales.

Finalmente, los observadores que consideramos minimales para especificar cada proc del TAD quedan de la siguiente manera:

El observador promos contiene las promociones activas: es un diccionario que tiene como clave al nombre de la promoción (nombrePromo) y como valor parametrosPromo, que es un struct que tiene un factor y un tope.

El observador transf es el historial de transferencias: es una secuencia de transacciones, donde las transacciones son un struct que tiene un origen (quien envía la transferencia), un destino (quien la recibe) y la cantidad a transferir.

El observador acu es el historial de acumulaciones: es un diccionario que tiene como clave a los usuarios y como valor una secuencia de acumulaciones. Una acumulación es un struct que contiene la distanciaVolada, una tupla con la promoción con la que se vuela y su factor, y las millasGanadas que se calculan mediante la fórmula dada por el enunciado:

$$
millasGanadas = distanciaVolada \cdot factorCategoria \cdot factorPromocion
$$

El observador canj es el historial de canjes: es un diccionario cuyas claves son usuarios y cuyo valor es una secuencia de enteros que representa las millas que se canjean en cada operación de canje que realiza el usuario.

El observador ref es un diccionario que toma como clave a un usuario y como valor una secuencia de enteros con el elemento 500, correspondientes a las millas ganadas por haber referido a alguien (donde tanto el referido como el referidor ganan sus 500 millas). No nos importa a quién refirió, ni por quién fue referido, sino únicamente el valor que ganó para poder contabilizarlo en millasTotales y millasDisponibles, y sobre todo para poder excluirlo en resumenTransacciones, que excluye las millas ganadas por referidos.

En el asegura del proc registrarUsuario hicimos un predicado seAgregoUsuario(s,u), donde tomamos la decisión de asegurarnos de que todos los usuarios queden registrados en los observadores, inicializando los diccionarios con la clave del nuevo usuario y su valor como una secuencia vacía.

El historial de transacciones del sistema es global y no discrimina por usuario, por lo tanto, no se modifica al registrar un usuario. Lo mismo sucede con las promociones, ya que no tienen relación con el registro de un usuario. Esta aclaración la hacemos dado que el enunciado pide explícitamente que las transacciones del usuario se inicien vacías, pero nuestras transacciones no están discriminadas por un usuario particular, sino que contemplan a los dos involucrados. Por lo tanto, no dependen de un único usuario y no pueden inicializarse como vacías para cada usuario, dado que las planteamos de manera diferente.

En esta línea, el enunciado dice que en todo momento debe garantizarse que las millas disponibles de un usuario no superen sus millas totales, pero por construcción, millasDisponibles = millasTotales - millasPerdidas, por lo tanto siempre ocurre que $millasDisponibles \leq millasTotales$, entonces no hace falta estar verificando continuamente predicados sobre auxiliares dado que están construidos de forma tal que se respeten las consignas del enunciado. Por otro lado, para cumplir que las operaciones que modifican el sistema deben preservar la integridad de los saldos (ningún usuario puede tener saldo negativo), verificamos que las millasDisponibles sean suficientes para realizar la transferencia o canje. Para que se respete que los identificadores de usuario sean números enteros positivos se requieren positivos para ser válidos como entrada, entre otros casos. De esta manera nos aseguramos respetar estos puntos por construcción.

Decidimos poner la palabra tupla antes de las tuplas dado que el símbolo de tuplas, structs, y secuencias son idénticos y no habría forma de diferenciarlos salvo contexto, especialmente para las tuplas puede resultar confuso por lo que agregamos explícitamente la palabra tupla antes de una tupla.

Hay un error en el enunciado de acumularMillas: si un usuario tiene millas totales mayores o iguales a 50.000, se considera de categoría Oro con su factor asociado, y si un usuario tiene millas totales mayores o iguales a 1.000.000, es de categoría Platino. Ahora bien, si un usuario supera o iguala las 1.000.000 millas totales, el usuario es Oro y Platino al mismo tiempo, lo cual sabemos que no es posible, ya que un usuario no puede estar en dos categorías diferentes al mismo tiempo. Tomamos la decisión de resolver este inconveniente del enunciado imponiendo que el factor Oro para el usuario sea válido cuando tenga menos de 1.000.000 de millas totales.

En transferirMillas encontramos un error de enunciado: dos usuarios pueden transferirse entre ellos infinitamente la misma cantidad una y otra vez, y ambos llegar a la categoría Platino. Por recomendación docente, decidimos seguir la directiva del enunciado, permitir el bug y dejar que el programador decida cómo afrontar este error.

En cuanto al tope de una promo, decidimos hacer lo siguiente: tener un tope igual a -1 significa que no hay tope. Esto lo podemos utilizar, por ejemplo, cuando creamos el sistema con el nombre de la promoción No Promo, o cuando creamos una promoción sin tope. El tope es un número que va bajando a medida que los usuarios vuelan con la promoción y acumulan millas, haciendo: $tope - acumuladoGlobalDeMillasConEsaPromo$ \ hasta llegar a 0. Mientras baja el tope, la promoción está activa y, cuando llega a 0, se elimina del sistema. Tomamos la decisión de validar en el requiere que las millas a volar no superen el tope de la promoción: si el vuelo supera el tope de la promoción, no puede realizarse con esa promoción.

\section{Especificación del TAD airMiles}

$/*$ Por sugerencia del corrector, para no repetir en cada proc que los observadores no involucrados no sufren modificaciones, dada nuestra construcción de observadores, usamos el predicado losDemasObservadoresNoCambian$(s,S_0)$ de forma flexible para indicar ese comportamiento y resumir los predicados del tipo: $s.observador = S_0.observador$ (excepto el/los que sí cambian) $/*$

\noindent nombrePromo ES $\str$

\noindent factor ES $\R$

\noindent parametrosPromo ES $\struct{factor:\R, tope:\R}$

\noindent trans ES $\struct{origen: \Z, destino: \Z, cantidad: \R}$

\noindent usuario ES $\Z$

\noindent acumulacion ES $\struct{distanciaVolada:\R, promo: tupla\tupla{nombrePromo,factor}, millasGanadas:\R}$

\noindent categoria ES $enum\{'Bronce', 'Plata', 'Oro', 'Platino'\}$

\begin{tad}{airMiles}
    \obs{promos}{\dict{nombrePromo}{parametrosPromo}}
    \\
    \obs{transf}{\seq{trans}}
    \\
    \obs{acu}{\dict{usuario}{\seq{acumulacion}}}
    \\
    \obs{canj}{\dict{usuario}{\seq{millas:\R}}}
    \\
    \obs{ref}{\dict{usuario}{\seq{cantidad:\Z}}}

    \bigskip
    
    \auxLargo{millasTotales}{s: airMiles, u: usuario}{\R}{sumaDeAcumulaciones(s,u) + sumaDeTransferenciasRecibidas(s,u) + sumaDeReferidos(s,u)}
    
    \bigskip
    
    \auxLargo{millasDisponibles}{s: airMiles, u: usuario}{\R}{millasTotales(s,u) - millasPerdidas(u,s)}
    
    \bigskip
    
    \auxLargo{sumaDeAcumulaciones}{s: airMiles, u: usuario}{\R}{\sum_{i=0}^{|s.acu[u]|-1}{s.acu[u][i].millasGanadas}}
    
    
    \bigskip
    
    \auxLargo{sumaDeTransferenciasRecibidas}{s: airMiles, u: usuario}{\R}{\sum_{i=0}^{|s.transf|-1}
        \operatorname{IfThenElse}\big(
            s.transf[i].destino = u, s.transf[i].cantidad,0\big)}
    
    \bigskip
    
    \auxLargo{sumaDeTransferenciasEnviadas}{s: airMiles, u: usuario}{\R}{\sum_{i=0}^{|s.transf|-1}
        \operatorname{IfThenElse}\big(
        s.transf[i].origen = u, s.transf[i].cantidad,0\big)}
    
    \bigskip
    
    \aux{sumaDeReferidos}{s: airMiles, u: usuario}{\R}{\sum_{i=0}^{|s.ref[u]|-1}{s.ref[u][i]}}

    \bigskip

    \auxLargo{sumaDeCanjes}{s: \Tipo{airMiles}, u: usuario}{\R}{\sum_{i=0}^{|s.canj[u]|-1}
    s.canj[u][i]}
    
    \bigskip

    \auxLargo{millasPerdidas}{u: usuario, s: \Tipo{airMiles}}{\R}{sumaDeCanjes(s,u) + sumaDeTransferenciasEnviadas(s,u)}
    
    \bigskip
    
    \auxLargo{cat}{s: airMiles, u:usuario}{categoria}{(res = "Bronce" \iff (millasTotales(s,u) < 10.000)) \ \land \\ (res = "Plata" \iff 10.000 \leq millasTotales(s,u) < 50.000) \ \land \\ (res = "Oro" \iff 50.000 \leq millasTotales(s,u) < 1.000.000) \ \land \\ (res = "Platino" \iff millasTotales(s,u) \geq 1.000.000)}
    
    \bigskip
    
    \auxLargo{factorCategoria}{s: airMiles, u:usuario}{\R}{(res = 1 \iff cat(s,u) = "Bronce") \ \land \\ (res = 1.5 \iff cat(s,u) = "Plata") \ \land \\ (res = 2 \iff cat(s,u) = "Oro") \ \land \\ (res = 0 \iff cat(s,u) = "Platino")}
    
    \bigskip
    
    \begin{proc}{crearSistema}{}{\Tipo{airMiles}}
     
        \requiere{True}
    
        \aseguraLargo{res.acu = \{\} \ \land \\ res.transf = <> \ \land \\ res.canj = \{\} \ \land \\ res.ref = \{\} \ \land \\ res.promos = \{"NoPromo" : \struct{1,-1}\}}
         
    \end{proc}
    
    \bigskip
    
    
    \begin{proc}{registrarUsuario}{\Inout s:\Tipo{airMiles}, \In u:\Tipo{usuario}}{}
    
        \requiere{s = S_0 \land u > 0 \land \neg usuarioEnSistema(s,u)}
    
        \aseguraLargo{seAgregoUsuario(s,u) \land losDemasObservadoresNoCambian(s,S_0)}
    \end{proc}
    
    \bigskip
    
    \predLargo{usuarioEnSistema}{s: airMiles, u: usuario}{u \in claves(s.acu)}
    
    \bigskip
    
    \predLargo{seAgregoUsuario}{s: airMiles, u: usuario}{s.acu = setKey(S_0.acu, u, <>) \land \\ s.canj = setKey(S_0.canj, u, <>) \land \\ s.ref = setKey(S_0.ref, u, <>)}

    \bigskip
    
    \begin{proc}{registrarUsuarioConReferidor}{\Inout s:\Tipo{airMiles}, \In ref:\Tipo{usuario}, \In u:\Tipo{usuario}}{}
    
        \requiere{s = S_0 \land u > 0 \land \neg usuarioEnSistema(s,u) \land usuarioEnSistema(s,ref)}
    
        \aseguraLargo{seAgregoUsuario(s,u) \ \yLuego \\ seAgregoReferido(s,S_0,u,ref) \land \\ losOtrosRefNoCambian(s, S_0, u, ref) \land \\ losDemasObservadoresNoCambian(s,S_0)}
    
    \end{proc}
    
    \bigskip
    
    \predLargo{seAgregoReferido}{s: airMiles, S_0: airMiles, u: usuario, ref: usuario}{s.ref[u] = S_0.ref[u] ++ <500> \ \land \\ s.ref[ref] = S_0.ref[ref] ++ <500>}
    
    \bigskip
    
    \predLargo{losOtrosRefNoCambian}{s: airMiles, S_0: airMiles, u: usuario, ref: usuario}{(\forall usu:\Z)(usu \in claves(S_0.ref) \implica usu \in claves(s.ref))\yLuego \\ (\forall usu:\Z)((usu \in claves(S_0.ref) \land usu \neq u \land usu \neq ref) \implicaLuego S_0.ref[usu] = s.ref[usu])}
    
    \bigskip
    
\begin{proc}{acumularMillas}
    {
    \Inout s: airMiles,
    \In u: usuario,
    \In distanciaVolada: \R,
    \In p: nombrePromo,
    }{}

    \requiereLargo{
        s = S_0
        \ \land \
        distanciaVolada>0
        \ \land \\ 
        \big((usuarioEnSistema(s,u)) \ \land \ 
        (existePromo(p,s))\big) \yLuego \\
        promoDisponeDeMillasParaVuelo(
            u,
            distanciaVolada,
            p,
            s,
            S_0
        )
    }

    \aseguraLargo{
        s.acu = setKey(S_0.acu, u, S_0.acu[u] ++ \\ \struct{distanciaVolada, tupla\tupla{p, S_0.promos[p].factor}, millasGanadas(S_0,distanciaVolada,p,u)})\land \\
        \big(promoNoTieneTope(p,s,S_0) \lor \\
    casoGastaElTopeDeLaPromo(u,distanciaVolada,p,s,S_0) \lor \\
    casoModificaElTopeDeLaPromo(u,distanciaVolada,p,s,S_0) \big) \land \\ losDemasObservadoresNoCambian(s,S_0)
    }
\end{proc}

\bigskip

\predLargo{existePromo}
{
    p: nombrePromo,
    s: airMiles
}{
    p \in claves(s.promos)
}

\bigskip

\predLargo{promoDisponeDeMillasParaVuelo}
{
    u: usuario,
    distanciaVolada: \R,
    p: nombrePromo,
    s: airMiles,
    S_0: airMiles
}{
   promoNoTieneTope(p,s,S_0)
    \lor \\ millasGanadas(S_0,distanciaVolada,p,u)
        \leq
        s.promos[p].tope}

\bigskip

\aux{millasGanadas}{S_0:airMiles, distanciaVolada:\R, p:nombrePromo, u:usuario)}{\R}{distanciaVolada*S_0.promos[p].factor*factorCategoria(S_0,u)}

\bigskip

\predLargo{promoNoTieneTope}
{
    p: nombrePromo,
    s:airMiles,
    S_0: airMiles
}{
    S_0.promos[p].tope = -1 \land
    s.promos[p]=S_0.promos[p]
}

\bigskip



\predLargo{casoGastaElTopeDeLaPromo}
{   u: usuario,
    distanciaVolada: \R,
    p: nombrePromo,
    s: airMiles,
    S_0: airMiles
}{      
    \big((S_0.promos[p].tope - millasGanadas(S_0,distanciaVolada,p,u)) = 0 \big) \land \\ s.promos = delKey(S_0.promos, p)}
            

\bigskip


\predLargo{casoModificaElTopeDeLaPromo}
{   u: usuario,
    distanciaVolada: \R,
    p: nombrePromo,
    s: airMiles,
    S_0: airMiles
}{
     \big((S_0.promos[p].tope
    - millasGanadas(S_0,distanciaVolada,p,u) \big) > 0 \ \land \\
    s.promos = setKey(S_0.promos, p, \\ \struct{S_0.promos[p].factor, S_0.promos[p].tope - millasGanadas(S_0,distanciaVolada,p,u)}}

\bigskip


\bigskip

\begin{proc}{canjearMillas}{\Inout s: \Tipo{airMiles}, \In u:\Tipo{usuario}, \In millas:\R}{}
          
        \requiereLargo{s = S_0 \ \land \ millas > 0  \ \land usuarioEnSistema(s,u) \ \yLuego \ millas \leq millasDisponibles(s,u)}
          
        \aseguraLargo{s.canj = setKey(S_0.canj, u, S_0.canj[u] ++ <millas>) \ \land \\ losDemasObservadoresNoCambian(s,S_0)}
          
    \end{proc}
    
    \bigskip
    
    
    \begin{proc}{transferirMillas}
    {
    \In o: \Tipo{usuario},
    \In d: \Tipo{usuario},
    \In m: \R,
    \Inout s: \Tipo{airMiles}
    }{
    }
        \requiereLargo{
            (s = S_0) \ \land \ m > 0 \ \land \ (o \neq d) 
            \ \land \ usuarioEnSistema(s, d) \ \land \\
            usuarioEnSistema(s, o)
             \ \yLuego \
            disponeDeMillas(o, m, s)
        }
        \aseguraLargo{
        s.transf = S_0.transf ++ \struct{origen: o, destino: d, cantidad: m}
        \land \\ losDemasObservadoresNoCambian(s,S_0)}
    \end{proc}

\bigskip


\predLargo{disponeDeMillas}{
u: usuario,
millasATransferir: \R,
s: airMiles
}{
    millasDisponibles(s,u) \geq millasATransferir
}


\bigskip
    
    \begin{proc}{consultarSaldo}{\In s:\Tipo{airMiles}, \In u:\Tipo{usuario}}{\R}
    
        \requiere{usuarioEnSistema(s,u)}
    
        \asegura{res = millasDisponibles(s,u)}
         
    \end{proc}
    
    \bigskip
    
    \begin{proc}{consultarCategoria}{\In s:\Tipo{airMiles}, \In u:\Tipo{usuario}}{\Tipo{categoria}}
    
        \requiere{usuarioEnSistema(s,u)}
    
        \asegura{res = cat(s,u)}
    
    \end{proc}
    

    \begin{proc}{rankingMillas}{\In N: \Z, \In s: \Tipo{airMiles}}{\seq{usuario}}

        \requiereLargo{N > 0}

        \aseguraLargo{
            estaOrdenadoSegunCantidadMillasDisponibles(res,s)
            \ \land \\
            todosUsuariosEstanEnElHistorial(res,s)
            \ \land \\ resTieneTama\textit{ñ}oMenorOIgualQueN(res, s, N) \ \land \\ todosUsuariosDistintos(res) \ \land \\ todosLosNoSeleccionadosTienenMenosOMismasMillas(res,s)}
    \end{proc}

\bigskip

\predLargo{estaOrdenadoSegunCantidadMillasDisponibles}{res: \seq{usuario}, s: \Tipo{airMiles}}{
    (\forall i:\Z)(
        0 \leq i < |res|-1
        \ \implicaLuego
        millasDisponibles(s,res[i]) \geq millasDisponibles(s,res[i+1])
    )}
    
\bigskip

\predLargo{todosUsuariosEstanEnElHistorial}{res: \seq{usuario}, s: \Tipo{airMiles}}{
    (\forall i:\Z)(
        0 \leq i < |res|
        \ \implicaLuego \
        res[i] \in claves(s.acu)
    )}
    
\bigskip

\predLargo{resTieneTamañoMenorOIgualQueN}{res:\seq{usuario}, s: airMiles, N: \Z}{(N \leq |claves(s.acu)| \ \land \ |res| = N)
            \ \lor \\
            (|claves(s.acu)| < N
            \ \land \ |res| = |claves(s.acu)|)}

    \bigskip
    
    \predLargo{todosUsuariosDistintos}{res:\seq{usuario}}{
    (\forall i:\Z)(
        0 \leq i < |res|
        \ \implicaLuego
        (\forall j:\Z)(
            0 \leq j < |res|
            \ \land\
            i \neq j
            \ \implicaLuego \
            res[i] \neq res[j]
        )
    )
}

\bigskip

\predLargo{todosLosNoSeleccionadosTienenMenosOMismasMillas}
{res:\seq{usuario},s:\Tipo{airMiles}}{
    (\forall u: usuario)(
        u \in claves(s.acu)
        \ \land\
        u \notin res \land |res| > 0
        \ \implicaLuego \\
        millasDisponibles(s,u)
        \leq
        millasDisponibles(s,res[|res|-1])
    )
}

\begin{proc}{resumenTransacciones}{
\In u: usuario,
\In s: airMiles
}{\struct{total: \R, canjeadas: \R, enviadas: \R, recibidas: \R}}
{
    \requiere{usuarioEnSistema(s,u)}
    \aseguraLargo{
        (res.total = millasTotales(s,u)) \land \\
        (res.canjeadas = sumaDeCanjes(s,u)) \land \\
        (res.enviadas = sumaDeTransferenciasEnviadas(s,u)) \land \\
        (res.recibidas = sumaDeTransferenciasRecibidas(s,u))
    }
}

\end{proc}



    \begin{proc}{iniciarPromocion}
    {
        \Inout s: \Tipo{airMiles},
        \In nombre: \str,
        \In factor: \R
    }{}
        \requiereLargo{
            \norm{nombre} > 0 \land
            factor \geq 1 \land
            s = S_0 \land \\
            \neg existePromo(nombre, s)
        }
        \aseguraLargo{
            s.promos = setKey(S_0.promos, nombre, \struct{factor: factor, tope: -1}) \land \\ losDemasObservadoresNoCambian(s,S_0)
        }
    \end{proc}

    \bigskip



    \begin{proc}{iniciarPromocionConTope}
    {
        \Inout s: \Tipo{airMiles},
        \In nombre: \str,
        \In factor: \R,
        \In tope: \R
    }{}
        \requiereLargo{
            \norm{nombre} > 0 \land
            factor \geq 1 \land 
            tope > 0 \land
            s = S_0 \land \\
            \neg existePromo(nombre, s)
        }
        \aseguraLargo{
            s.promos = setKey(S_0.promos, nombre, \struct{factor: factor, tope: tope}) \land \\ losDemasObservadoresNoCambian(s,S_0))
        }
    \end{proc}

    \bigskip



    \begin{proc}{finalizarPromocion}
    {
        \Inout s: \Tipo{airMiles},
        \In nombre: \seq{\cha}
    }{}
        \requiereLargo{
            \norm{nombre} > 0 \land
            nombre \neq "NoPromo" \land
            existePromo(nombre,s) \land
            s = S_0
        }
        \aseguraLargo{
            s.promos = delKey(S_0.promos, nombre) \land \\ losDemasObservadoresNoCambian(s,S_0)
        }
    \end{proc}

    \begin{proc}{elQueTieneMasMillas}{\In s: \Tipo{airMiles}}{usuario}

        \requiereLargo{|claves(s.acu)| > 0}

        \aseguraLargo{
            usuarioEnSistema(s,res)
            \ \yLuego \\ tieneMasMillasQueLosDemas(res,s)
        }

    \end{proc}
    
    \predLargo{tieneMasMillasQueLosDemas}{res: usuario, s: airMiles}{(\forall u: usuario)(u \in claves(s.acu) \ \implicaLuego \ millasTotales(s,u) \leq millasTotales(s,res))}

    \bigskip

    \bigskip
 
    \begin{proc}{elMasCanjeador}{\In s: \Tipo{airMiles}}{usuario}

        \aseguraLargo{usuarioEnSistema(s, res) \yLuego tieneMasPerdidasQueLosDemas(res,s)
        }

\begin{proc}{paresTransferidoresExclusivos}
    {\In s: \Tipo{airMiles}}
    {\seq{tupla\tupla{usuario, usuario}}}

    \requiereLargo{True}

    \aseguraLargo{
        todosLosParesEnResSonExclusivos(res,s)
        \ \land \\
        enResEstanTodosLosExclusivos(res,s)
        \ \land \\
        noHayParesRepetidos(res)
        \ \land \\
        noSeInviertenEnRes(res)
    }

\end{proc}

\bigskip


% Existe al menos una transferencia entre a y b
\predLargo{sonTransferidores}
    {a: usuario, b: usuario, s: airMiles}
{
    (\exists i:\Z)(
        0 \leq i < |s.transf|
        \ \yLuego
        (
            (s.transf[i].origen = a
            \land
            s.transf[i].destino = b)
            \ \lor \\
            (s.transf[i].origen = b
            \land
            s.transf[i].destino = a)
        )
    )
}

\bigskip


% a solamente le transfiere a b
\predLargo{usuarioAsoloLeTransfiereExclusivamenteAlUsuarioB}
    {a: usuario, b: usuario, s: airMiles}
{
    (\forall i:\Z)(
        0 \leq i < |s.transf|
        \ \implicaLuego
        (
            s.transf[i].origen = a
            \implica
            s.transf[i].destino = b
        )
    )
}

\bigskip


% b solamente le transfiere a a
% Se obtiene reutilizando el predicado anterior.
\predLargo{sonTransferidoresExclusivos}
    {a: usuario, b: usuario, s: airMiles}
{
    sonTransferidores(a,b,s)
    \ \land \\
    usuarioAsoloLeTransfiereExclusivamenteAlUsuarioB(a,b,s)
    \ \land \\
    usuarioAsoloLeTransfiereExclusivamenteAlUsuarioB(b,a,s)
}

\bigskip


% Todo par que aparece en res es exclusivo
\predLargo{todosLosParesEnResSonExclusivos}
    {res:\seq{tupla\tupla{usuario, usuario}},
     s:\Tipo{airMiles}}
{
    (\forall i:\Z)(
        0 \leq i < |res|
        \ \implicaLuego \
        sonTransferidoresExclusivos(
            res[i]_0,
            res[i]_1,
            s
        )
    )
}

\bigskip


% Todo par exclusivo aparece en res
\predLargo{enResEstanTodosLosExclusivos}
    {res:\seq{tupla\tupla{usuario, usuario}},
     s:\Tipo{airMiles}}
{
    (\forall a,b:usuario)((
        (
            usuarioEnSistema(s,a)
            \land
            usuarioEnSistema(s,b)
        )
         \yLuego \\
            sonTransferidoresExclusivos(a,b,s))
            \implicaLuego
            (tupla\tupla{a,b} \in res \lor tupla\tupla{b,a} \in res))}

\bigskip


% No se repite exactamente el mismo par
\predLargo{noHayParesRepetidos}
    {res:\seq{tupla\tupla{usuario, usuario}}}
{
    (\forall i,j:\Z)(
        (
            0 \leq i < |res|
            \land
            0 \leq j < |res|
            \land
            i \neq j
        )
        \ \implicaLuego
        res[i] \neq res[j]
    )
}

\bigskip


% No aparecen ambos órdenes del mismo par
\predLargo{noSeInviertenEnRes}
    {res:\seq{tupla\tupla{usuario, usuario}}}
{
    (\forall i:\Z)(
        0 \leq i < |res|
        \ \implicaLuego
        tupla\tupla{res[i]_1,res[i]_0} \notin res
    )}
